# Komek by ticket

Komek by ticket — это Laravel-проект для работы с билетами в кино.

Приложение позволяет пользователям просматривать фильмы, доступные сеансы, время начала, цены билетов и залы, искать фильмы и подготавливать заказ билетов онлайн.

## Запустить

Установить Vite-зависимости:

```bash
npm install
```

Установить Laravel-зависимости:

```bash
composer install
```

Собрать Vite-ресурсы:

```bash
npm run build
```

Запустить Laravel-сервер:

```bash
php artisan serve
```

Проект будет доступен по адресу:

```text
http://localhost:8000
```
